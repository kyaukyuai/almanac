# v0.10 RC Smoke

This smoke validates the v0.10 answer-trust and compile-stability release:
optional answer entailment judging, source and fixture stability diagnostics,
retrieval readiness, deterministic ask-suite operations, and real-provider
answer replay. Use fresh disposable roots. Deterministic replay, default
`ask-suite`, `profile`, and `doctor` do not call an LLM provider. The
entailment judge and Enterprise AI compile/ask sections require an explicit
provider.

Run from the repository root.

## 1. Static Gates

```bash
git switch main

git diff --check
bun run typecheck
bun test
```

Expected result:

- whitespace check passes,
- typecheck passes,
- full test suite passes.

## 2. sqlite-demo Deterministic Ask, Replay, Suite, Judge, Refresh

Create a fresh offline demo:

```bash
SQLITE_ROOT="$(mktemp -d -t almanac-v010-sqlite-smoke)"

bun src/cli.ts demo --root "$SQLITE_ROOT"
bun src/cli.ts inspect sqlite-demo --root "$SQLITE_ROOT"
bun src/cli.ts profile sqlite-demo --root "$SQLITE_ROOT"
bun src/cli.ts benchmark sqlite-demo --root "$SQLITE_ROOT"
```

Expected readiness signal:

- `profile` shows `retrieval      fts-only: SQLite FTS is active; embeddings
  are optional`,
- `doctor` treats missing optional embeddings as ok,
- answer mode starts as `needs-validation` until a saved answer fixture and
  suite evidence exist.

Run a deterministic mock-provider answer and save the answer artifact:

```bash
export ALMANAC_LLM=mock
export ALMANAC_MOCK_RESPONSES="$(
  cat <<'JSON'
{
  "answer-planner@planner-v1": [
    "{\"action\":\"call_tool\",\"toolName\":\"query_facts\",\"input\":{\"q\":\"transactions atomic\",\"limit\":3}}",
    "{\"action\":\"stop\",\"reason\":\"enough-evidence\"}"
  ],
  "answer-synthesis@synthesis-v1": "{\"status\":\"ok\",\"answer\":\"SQLite transactions are atomic.\",\"citations\":[{\"sourceId\":\"sqlite-transactions\",\"url\":\"https://www.sqlite.org/lang_transaction.html\",\"fetchedAt\":\"2026-01-01T00:00:00.000Z\"}]}"
}
JSON
)"

sqlite_answer_json="$SQLITE_ROOT/sqlite-answer.json"

bun src/cli.ts ask sqlite-demo \
  "Are SQLite transactions atomic?" \
  --save \
  --label rc-answer \
  --json \
  --root "$SQLITE_ROOT" \
  > "$sqlite_answer_json"

jq '{answerId, status, citations: (.citations | length), toolCalls: (.toolCalls | length), quality: .trace.quality.status}' \
  "$sqlite_answer_json"

sqlite_answer_id="$(jq -r '.answerId' "$sqlite_answer_json")"

unset ALMANAC_LLM
unset ALMANAC_MOCK_RESPONSES
```

Replay the saved answer without a provider, author a fixture, and run the
default suite:

```bash
bun src/cli.ts ask-replay sqlite-demo \
  --from-runs \
  --label rc-answer \
  --json \
  --root "$SQLITE_ROOT"

bun src/cli.ts ask-fixtures init sqlite-demo \
  --json \
  --root "$SQLITE_ROOT"

bun src/cli.ts ask-fixtures add-from-run sqlite-demo "$sqlite_answer_id" \
  --fixture-id sqlite-transactions-atomic \
  --json \
  --root "$SQLITE_ROOT"

bun src/cli.ts ask-suite sqlite-demo \
  --json \
  --root "$SQLITE_ROOT"
```

Run the optional entailment judge with the mock provider. This is explicit and
provider-backed; default replay and default suite stay provider-free.

```bash
export ALMANAC_LLM=mock
export ALMANAC_MOCK_RESPONSES="$(
  cat <<'JSON'
{
  "answer-entailment@judge-v1": "{\"verdict\":\"supported\",\"summary\":\"The citation supports the atomic transaction claim.\",\"claims\":[{\"claim\":\"SQLite transactions are atomic.\",\"status\":\"supported\",\"citationIndexes\":[0],\"reason\":\"The cited SQLite transaction documentation supports atomic transactions.\"}]}"

)"

bun src/cli.ts ask-replay sqlite-demo \
  --from-runs \
  --label rc-answer \

  --json \

  --judge \
  --json \
  --root "$SQLITE_ROOT"
```

## 3. Enterprise AI Fresh Compile Smoke

Run only when `ANTHROPIC_API_KEY` is available. `BRAVE_SEARCH_API_KEY` improves
source discovery coverage; without it, the compile may rely more heavily on
direct probes and GitHub/community discovery.

```bash
test -n "$ANTHROPIC_API_KEY" || {
  echo "ANTHROPIC_API_KEY is required for Enterprise AI RC smoke"
  exit 1
}

export ALMANAC_ROOT="$(mktemp -d -t almanac-v010-enterprise-ai-smoke)"

bun src/cli.ts new "Enterprise AI" \
  --slug enterprise-ai-smoke \
  --profile mixed \
  --depth standard \
  --scope "Enterprise AI adoption and operations for organizations: AI governance, risk management, evaluation, security, compliance, deployment patterns, observability, and operating-model decisions for production AI systems." \
  --source "https://www.nist.gov/itl/ai-risk-management-framework" \
  --source "https://owasp.org/www-project-top-10-for-large-language-model-applications/" \
  --source "https://atlas.mitre.org/" \
  --root "$ALMANAC_ROOT"

bun src/cli.ts inspect enterprise-ai-smoke --root "$ALMANAC_ROOT"
bun src/cli.ts profile enterprise-ai-smoke --root "$ALMANAC_ROOT"
bun src/cli.ts benchmark enterprise-ai-smoke --root "$ALMANAC_ROOT"

jq -r '.source.sourceId' \
  "$ALMANAC_ROOT/enterprise-ai-smoke/extracted/facts.jsonl" \
  | sort | uniq -c

jq '.results[] | select(.status!="pass") | {fixtureId, kind, reason, observed}' \
  "$ALMANAC_ROOT/enterprise-ai-smoke/.compile/benchmark-result.json"
```

If a provider timeout halts source evaluation, rerun from the failed stage:

```bash
bun src/cli.ts update enterprise-ai-smoke \
  --from-stage 02b-source-discovery-evaluator \
  --no-bump \
  --root "$ALMANAC_ROOT"
```

Expected Enterprise AI compile result:

- all compile stages complete,
- generated benchmark coverage is at or above 8 positive / 5 negative / 13
  total,
- benchmark passes with cited positives and negative refusals,
- `sources enterprise-ai-smoke --json` exposes source-set stability when a
  Stage 2 rerun compares against prior accepted sources,
- `.compile/stage11-output.json` records coverage floor and preflight attempt
  stability diagnostics,
- `profile` and `doctor` show retrieval readiness without hidden provider
  calls.

## 4. Real Provider Ask, Saved Replay, Fixture Suite, Optional Judge

Run after the Enterprise AI compile smoke has produced `ALMANAC_ROOT`.

```bash
test -n "$ANTHROPIC_API_KEY" || {
  echo "ANTHROPIC_API_KEY is required for real provider ask smoke"
  exit 1
}

enterprise_answer_json="$ALMANAC_ROOT/enterprise-ai-smoke-answer.json"

ask_exit=0
bun src/cli.ts ask enterprise-ai-smoke \
  "What governance checks should precede production rollout?" \
  --save \
  --label rc-real-provider \
  --json \
  --root "$ALMANAC_ROOT" \
  > "$enterprise_answer_json" || ask_exit=$?

if [ "$ask_exit" -gt 1 ]; then
  cat "$enterprise_answer_json"
  exit "$ask_exit"
fi

answer_status="$(jq -r '.status' "$enterprise_answer_json")"
if [ "$answer_status" != "ok" ] && [ "$answer_status" != "abstained" ]; then
  cat "$enterprise_answer_json"
  exit 1
fi

jq '{answerId, status, citations: (.citations | length), toolCalls: (.toolCalls | length), quality: .trace.quality.status}' \
  "$enterprise_answer_json"

enterprise_answer_id="$(jq -r '.answerId' "$enterprise_answer_json")"

bun src/cli.ts ask-replay enterprise-ai-smoke \
  --from-runs \
  --label rc-real-provider \
  --json \
  --root "$ALMANAC_ROOT"
```

Promote the answer to an Enterprise AI fixture only when the saved answer has
at least one tool call:

```bash
if jq -e '(.toolCalls | length) > 0' "$enterprise_answer_json" >/dev/null; then
  bun src/cli.ts ask-fixtures init enterprise-ai-smoke \
    --json \
    --root "$ALMANAC_ROOT"

  bun src/cli.ts ask-fixtures add-from-run enterprise-ai-smoke "$enterprise_answer_id" \
    --fixture-id enterprise-ai-governance-rollout \
    --json \
    --root "$ALMANAC_ROOT"

  bun src/cli.ts ask-suite enterprise-ai-smoke \
    --json \
    --root "$ALMANAC_ROOT"

  bun src/cli.ts ask-suite enterprise-ai-smoke \
    --judge \
    --json \
    --root "$ALMANAC_ROOT"

  bun src/cli.ts refresh run enterprise-ai-smoke \
    --from-stage 12-benchmark-run \
    --ask-suite \
    --save \
    --label rc-enterprise-ai-ask-suite \
    --json \
    --root "$ALMANAC_ROOT"
else
  echo "saved answer had no tool calls; fixture promotion skipped"
fi

bun src/cli.ts profile enterprise-ai-smoke --root "$ALMANAC_ROOT"
bun src/cli.ts doctor enterprise-ai-smoke --root "$ALMANAC_ROOT"
```

Expected real-provider result:

- answer status is either `ok` with citations or a correct abstention,
- saved answer artifact includes planner, tool, citation, synthesis, quality,
  and artifact metadata sections,
- saved-answer replay passes without another provider call,
- if a fixture is promoted, default `ask-suite` passes without provider calls,
- optional `ask-suite --judge` either passes or produces a documented
  unsupported/uncertain claim outcome for review,
- saved refresh artifact records `askSuite.status` as `passed`,
- latest answer status, latest suite status, quality gate, and retrieval mode
  appear in `profile` and `doctor`.
