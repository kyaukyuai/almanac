# v0.17 RC Smoke

This is the release-candidate smoke for the v0.17 Guided First Useful
Almanac release. It validates empty-root first-use guidance, natural-language
setup planning, source checklist handoff, sqlite-demo first-answer promotion,
abstention recovery, Studio first-use/recovery visibility, and the separated
Enterprise AI provider smoke.

Run from the repository root. Use fresh disposable roots. Sections 1-6 are
provider-free or use the deterministic mock provider only. Section 7 is
provider-backed and requires intentional credentials.

## 5. Abstention Recovery

Run a deterministic mock abstention and confirm the recovery path is visible
without weakening cite-or-abstain:

```bash
mock_abstain_responses='{"answer-planner@planner-v1":["{\"action\":\"call_tool\",\"toolName\":\"query_facts\",\"input\":{\"q\":\"not in demo\",\"limit\":3}}","{\"action\":\"stop\",\"reason\":\"no-evidence\"}"],"answer-synthesis@synthesis-v1":"{\"status\":\"abstained\",\"abstentionReason\":\"no-citations\",\"citations\":[]}"}'

set +e
ALMANAC_LLM=mock ANTHROPIC_API_KEY= BRAVE_SEARCH_API_KEY= ALMANAC_MOCK_RESPONSES="$mock_abstain_responses" \
  bun src/cli.ts ask sqlite-demo \
```

## 6. Studio First-Use And Recovery Surface

Start the local Studio on a random localhost port and inspect the first-use,
source checklist, operation, and recovery surfaces. Use `--json` so the URL is
machine-readable.

```bash
studio_out="$(mktemp -t almanac-v017-studio-out)"
bun src/cli.ts studio \
  --port 0 \
  --json \
  --root "$DEMO_ROOT" \
  > "$studio_out" 2>&1 &
studio_pid=$!

for i in $(seq 1 40); do
  if jq -e '.url' "$studio_out" >/dev/null 2>&1; then
    break
  fi
  sleep 0.25
done

studio_url="$(jq -r '.url' "$studio_out")"
test -n "$studio_url"

curl -fsS "$studio_url/" > "$DEMO_ROOT/studio.html"
curl -fsS "$studio_url/api/inventory" > "$DEMO_ROOT/studio-inventory.json"
curl -fsS "$studio_url/api/status/sqlite-demo" > "$DEMO_ROOT/studio-sqlite-demo.json"

grep -E 'First Use|Answer Recovery|Guided Operations|Suggested Questions|sqlite-demo|Do not fabricate' \
  "$DEMO_ROOT/studio.html"

jq '{count: .counts.total, firstUse: .almanacs[0].firstUse, recovery: .almanacs[0].firstAnswerRecovery, operations: [.almanacs[0].operations[] | {label, providerRequired, mutation, studioRunnable, blockedReason}]}' \
  "$DEMO_ROOT/studio-inventory.json"

jq '{firstUse, recovery: .firstAnswerRecovery, sourceChecklist: .firstUse.sourceChecklist, operations: [.operations[] | {id, label, providerRequired, mutation, studioRunnable, blockedReason}]}' \
  "$DEMO_ROOT/studio-sqlite-demo.json"
```

Expected result:

- Studio binds to `127.0.0.1`,
- HTML includes First Use and Answer Recovery sections,
- `/api/inventory` and `/api/status/sqlite-demo` expose first-use,
  source-checklist, operation, and recovery metadata,
- provider-backed operations remain copyable CLI handoff,
- safe provider-free operations remain Studio runnable when available.

Run one safe provider-free Studio operation and reject an unsafe/provider
handoff:

```bash
studio_provider_free_id="$(
  jq -r '.operations[] | select(.studioRunnable==true and .providerRequired==false) | .id' \
    "$DEMO_ROOT/studio-sqlite-demo.json" \
    | head -1
)"

studio_provider_id="$(
  jq -r '.operations[] | select(.providerRequired==true and .studioRunnable==false) | .id' \
    "$DEMO_ROOT/studio-sqlite-demo.json" \
    | head -1
)"

test -n "$studio_provider_free_id"
test -n "$studio_provider_id"

curl -fsS -X POST "$studio_url/api/operations/sqlite-demo/$studio_provider_free_id/run" \
  | tee "$DEMO_ROOT/studio-operation-provider-free.json" \
  | jq '{operationId, status, exitCode, provider, artifactsWritten, summary, next: .nextOperation.label}'

curl -sS -X POST "$studio_url/api/operations/sqlite-demo/$studio_provider_id/run" \
  -o "$DEMO_ROOT/studio-operation-provider-blocked.json" \
  -w '%{http_code}\n' \
  | grep '^200$'

jq '{operationId, status, exitCode, provider, summary, reasons}' \
  "$DEMO_ROOT/studio-operation-provider-blocked.json"

curl -sS -X POST "$studio_url/api/inventory" -o /dev/null -w '%{http_code}\n' \
  | grep '^405$'

kill -INT "$studio_pid"
wait "$studio_pid" || true
```

Expected result:

- Studio POST returns the structured operation result envelope,
- safe provider-free operation exits `0`,
- provider-backed action is blocked instead of executed,
- unrelated POST requests remain rejected with `405`,
- page load and API reads do not call a provider.
