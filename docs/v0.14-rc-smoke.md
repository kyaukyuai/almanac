# v0.14 RC Smoke

This is the release-candidate smoke for the v0.14 First-Run Guided Experience
release. It validates the path for a user who does not want to learn the
artifact model first: ask for the next step, create the offline demo, inspect
it with user-facing terminology, seed answer checks without provider
credentials, and open a local read-only studio.

Run from the repository root. Use fresh disposable roots. Sections 1-6 are
provider-free. Section 7 is provider-backed and requires `ANTHROPIC_API_KEY`.

Stage 12 refresh boundary:


- `refresh run --from-stage 12-benchmark-run --ask-suite --save` exits `0`,
- `profile` reports `answer readiness ready`, `answer checks 1 found`, and
  `quality gate pass`,

## 6. Local Read-Only Studio

Start the local studio on a random localhost port:

```bash
bun src/cli.ts studio --root "$GUIDED_ROOT" --port 0 \
  > "$GUIDED_ROOT/studio.log" 2>&1 &
studio_pid=$!

for i in $(seq 1 40); do
  if grep -q 'studio: http://' "$GUIDED_ROOT/studio.log"; then
    break
  fi
  sleep 0.25
done

studio_url="$(sed -n 's/^studio: //p' "$GUIDED_ROOT/studio.log" | head -n1)"
test -n "$studio_url"

curl -fsS "$studio_url" > "$GUIDED_ROOT/studio.html"
curl -fsS "$studio_url/api/inventory" > "$GUIDED_ROOT/studio-inventory.json"

grep -E 'read-only|sqlite-demo|Next best action|Health' "$GUIDED_ROOT/studio.html"
jq '{root, count: .counts.total, ids: [.almanacs[].almanacId]}' \
  "$GUIDED_ROOT/studio-inventory.json"

kill -INT "$studio_pid"
wait "$studio_pid" || true
grep 'studio stopped' "$GUIDED_ROOT/studio.log"
```

Expected result:

- CLI prints `studio: http://127.0.0.1:<port>`,
- HTML includes `sqlite-demo` and `read-only`,
- `/api/inventory` returns one almanac id, `sqlite-demo`,
- mutating next actions are shown as copyable CLI commands only,
- Ctrl-C/SIGINT stops the process and prints `studio stopped`.

Localhost boundary check:

```bash
cat "$GUIDED_ROOT/studio-nonlocal.txt"
```

- the message says studio only binds to localhost.

## 7. Enterprise AI Provider Smoke

Run this section only when provider credentials are intentionally available.
The root is disposable; Enterprise AI remains generated on demand.

```bash
test -n "$ANTHROPIC_API_KEY" || {
  echo "ANTHROPIC_API_KEY is required for Enterprise AI RC smoke"
  exit 1
}

git switch main
git pull --ff-only

ENTERPRISE_ROOT="$(mktemp -d -t almanac-v014-enterprise-ai-smoke)"

bun src/cli.ts start \
  "Build an almanac for Enterprise AI production governance" \
  --json \
  --root "$ENTERPRISE_ROOT" \
  | jq '{status, domain: .goalDraft.domain, slug: .goalDraft.slug, providerRequired: .goalDraft.providerRequiredForCompile}'

bun src/cli.ts new "Enterprise AI" \
  --slug enterprise-ai-smoke \
  --profile mixed \
  --depth standard \
  --scope "Enterprise AI adoption and operations for organizations: AI governance, risk management, evaluation, security, compliance, deployment patterns, observability, and operating-model decisions for production AI systems." \
  --source "https://www.nist.gov/itl/ai-risk-management-framework" \
  --source "https://owasp.org/www-project-top-10-for-large-language-model-applications/" \
  --source "https://atlas.mitre.org/" \
  --root "$ENTERPRISE_ROOT"

bun src/cli.ts inspect enterprise-ai-smoke --root "$ENTERPRISE_ROOT"
bun src/cli.ts profile enterprise-ai-smoke --root "$ENTERPRISE_ROOT"
bun src/cli.ts benchmark enterprise-ai-smoke --root "$ENTERPRISE_ROOT"
bun src/cli.ts maintain enterprise-ai-smoke --dry-run --json --root "$ENTERPRISE_ROOT" \
  | jq '{status, refresh: .refresh.status, benchmark: .benchmark.status, answer: .answer.status, plan: [.plan[] | {id, status, providerRequired}]}'
```

Run a real-provider answer and replay the saved artifact without another
provider call:

```bash
enterprise_answer_json="$ENTERPRISE_ROOT/enterprise-ai-smoke-answer.json"

ask_exit=0
bun src/cli.ts ask enterprise-ai-smoke \
  "What governance checks should precede production rollout?" \
  --save \
  --label rc-real-provider \
  --json \
  --root "$ENTERPRISE_ROOT" \
  > "$enterprise_answer_json" || ask_exit=$?

if [ "$ask_exit" -gt 1 ]; then
  cat "$enterprise_answer_json"
  exit "$ask_exit"
fi

answer_status="$(jq -r '.status' "$enterprise_answer_json")"
if [ "$answer_status" != "ok" ] && [ "$answer_status" != "abstained" ]; then
  cat "$enterprise_answer_json"
  exit 1
fi

jq '{answerId, status, citations: (.citations | length), toolCalls: (.toolCalls | length), quality: .trace.quality.status}' \
  "$enterprise_answer_json"

bun src/cli.ts ask-replay enterprise-ai-smoke \
  --from-runs \
  --label rc-real-provider \
  --json \
  --root "$ENTERPRISE_ROOT"
```

Expected result:

- compile reaches health `ok` or a clearly actionable attention state,
- benchmark passes and citation rate is nonzero,
- maintenance dry-run surfaces provider-required refresh work explicitly,
- real-provider answer exits `0` for `ok` or `1` for a valid abstention,
- saved answer replay passes without another provider call.
