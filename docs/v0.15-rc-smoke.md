# v0.15 RC Smoke

This is the release-candidate smoke for the v0.15 Guided Activation release.
It validates the path from first orientation to a saved, replayable answer:
activation milestones, guided create apply, suggested questions, first-answer
guidance, Studio activation state, and the separated Enterprise AI provider
smoke.

Run from the repository root. Use fresh disposable roots. Sections 1-8 are
provider-free or use the deterministic mock provider only. Section 9 is
provider-backed and requires `ANTHROPIC_API_KEY`.

## 7. Studio Activation Surface

Start the local Studio on a random localhost port and inspect the activation
HTML/API. Use `--json` so the URL is machine-readable.

```bash
studio_out="$(mktemp -t almanac-v015-studio-out)"
bun src/cli.ts studio \
  --port 0 \
  --json \
  --root "$ACTIVATION_ROOT" \
  > "$studio_out" 2>&1 &
studio_pid=$!

for i in $(seq 1 40); do
  if jq -e '.url' "$studio_out" >/dev/null 2>&1; then
    break
  fi
  sleep 0.25
done

studio_url="$(jq -r '.url' "$studio_out")"
test -n "$studio_url"

curl -fsS "$studio_url/" > "$ACTIVATION_ROOT/studio.html"
curl -fsS "$studio_url/api/inventory" > "$ACTIVATION_ROOT/studio-inventory.json"
curl -fsS "$studio_url/api/status/sqlite-demo" > "$ACTIVATION_ROOT/studio-sqlite-demo.json"

grep -E 'Activation|Suggested Questions|First Answer|sqlite-demo|almanac ask sqlite-demo' \
  "$ACTIVATION_ROOT/studio.html"

jq '{count: .counts.total, activation: .almanacs[0].activation, suggested: .almanacs[0].suggestedQuestions[0].question, next: .almanacs[0].nextBestAction}' \
  "$ACTIVATION_ROOT/studio-inventory.json"

jq '{activation, suggested: .suggestedQuestions[0].question, commands: [.commands[].command]}' \
  "$ACTIVATION_ROOT/studio-sqlite-demo.json"

curl -sS -X POST "$studio_url/api/inventory" -o /dev/null -w '%{http_code}\n' \
  | grep '^405$'

kill -INT "$studio_pid"
wait "$studio_pid" || true
```

Expected result:

- Studio binds to `127.0.0.1`,
- HTML includes activation, first-answer guidance, suggested questions, and
  copyable `almanac ask sqlite-demo ...` commands,
- `/api/inventory` and `/api/status/sqlite-demo` include activation summaries,
  suggested questions, and copyable commands,
- POST requests remain rejected with `405`,
- page load and API reads do not call a provider.
